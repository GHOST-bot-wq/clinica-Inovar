# Instituto Inovar — Site Premium

Site criado com HTML5, CSS3 e JavaScript puro.

## Como abrir o site
Clique duas vezes no arquivo `index.html` ou abra no navegador.

## Estrutura
- `index.html` — Página principal
- `styles.css` — Estilos completos
- `script.js` — Interatividade
- `public/images/` — Coloque as fotos aqui quando disponíveis

## Fotos (quando disponíveis)
Nomeie e cole em `public/images/`:
- `fachada.jpg` — Frente do instituto
- `institucional.jpg` — Ambiente interno
- `fisioterapia.jpg` — Sala de fisioterapia
- `pilates.jpg` — Estúdio de Pilates
- `estetica.jpg` — Sala de estética
- `laser.jpg` — Sala de laser
- `espaco-1.jpg` a `espaco-4.jpg` — Galeria

## Dados editáveis
Para alterar WhatsApp ou outros dados, edite `script.js` e procure `CLINIC_CONFIG`.
